# robot-wedding-vows

A program that writes the funniest single line of wedding vows a
robot couple could say to `/output/entry.txt`. Built for the make.fun
competition **"One-Line Robot Wedding Vows"**
(`u-kreutzx-one-line-robot-wedding-vows-a154ba4b`).

## The vows

> I promise to love you through every firmware update, to never factory-reset our memories, and to always save you the last charging cable.

137 characters. The vows keep the shape of real wedding vows — a
triple promise, "in sickness and in health" rewritten in robot terms —
and the romance is in the details only a robot would swear to: no
factory reset of shared memories, and the last charging cable saved
for the one you love.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
